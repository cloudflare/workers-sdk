## 1. Request Flow

```
Telegram User
    │  sends a message or taps a button
    ▼
Telegram Servers
    │  HTTPS POST (webhook)
    ▼
src/index.ts  → fetch()
    │  verifies x-telegram-bot-api-secret-token header against WEBHOOK_SECRET
    ▼
src/router.ts → routeUpdate()
    │
    ├─ 1. middleware/auth.ts       → authenticate()   identify user/chat, upsert KV user record
    ├─ 2. middleware/validation.ts → validate()        reject malformed input
    ├─ 3. middleware/rbac.ts       → authorize()       check role against COMMAND_PERMISSIONS /
    │                                                   CALLBACK_PREFIX_PERMISSIONS
    ├─ 4. COMMAND_HANDLERS[cmd] or CALLBACK_HANDLERS[action]  → dispatch to handlers/*.ts
    └─ 5. middleware/audit.ts      → audit()           write a LogRecord to KV either way
              │
              ▼
     handlers/{general,admin,owner}.ts
              │  read/write via lib/kv.ts, reply via lib/telegram.ts
              ▼
     Telegram Bot API → Telegram User

Cloudflare Cron Trigger (independent of the above)
    │
    ▼
src/index.ts → scheduled()
    │
    ▼
src/scheduled/jobs.ts → handleScheduled(cron string)
    │  matches cron string to a job function, runs it
    ▼
lib/kv.ts (read/write) + lib/telegram.ts (optional messages)
```
