Infer a Worker's cron expressions from `cloudflare.config.ts`

`triggers.scheduled(...)` now keeps the literal type of `schedule`, and the new `InferCrons` type collects every schedule across all branches of a config into a string union. Types generated by the Vite plugin and by Wrangler's experimental `--experimental-new-config` mode declare it as `Cloudflare.GlobalProps["crons"]`, so you can read it with `Cloudflare.GlobalProp<"crons", string>`.

`InferCrons` falls back to `string` when the config has no scheduled triggers or when any schedule's type is `string`, such as one read from `process.env`. `ScheduledController.cron` still has the type `string` until the Workers runtime types read this property.
