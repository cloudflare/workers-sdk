Start local Workflows from Artifacts events

Configure `triggers.events` in your Wrangler configuration to deliver local Artifacts repository and token events to a Workflow defined by the same Worker. The updated Miniflare runtime and Wrangler adapter support this beta feature through Vite plugin v1. Local push, clone, fetch, and queue subscriptions remain unsupported.
