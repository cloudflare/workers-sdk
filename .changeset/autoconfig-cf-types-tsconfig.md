Include the types generated by `cf workers types` in `tsconfig.json` when configuring for `cf`

`cf workers types` writes the Worker's types to `.cloudflare/types`, which include globs such as `**/*` don't match, so type checking couldn't find `Env` after autoconfig. Autoconfig now adds `.cloudflare/types` to the `include` array in `tsconfig.json` for `cf` projects with a Worker, as `cf init` does for new projects. When `tsconfig.json` has no `include` array, autoconfig asks you to add the entry yourself.
